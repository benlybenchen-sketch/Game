# Ảnh cho game "Hồ đòi người": prompt để dán vào Google AI Studio (Nano Banana Pro)

**Cách làm:**
1. Mở aistudio.google.com và chọn model **Nano Banana Pro** (Gemini 3 Pro Image).
2. Dán **nguyên văn** prompt tiếng Anh bên dưới (tiếng Anh cho kết quả ổn định hơn), chọn đúng **tỉ lệ khung hình**.
3. Tải ảnh về, **đổi tên đúng như tên file** ghi ở từng mục, rồi gửi lên chat. Gửi nhiều ảnh một lần được.
4. Ảnh nào xấu thì bấm tạo lại. Không cần đủ hết: ảnh nào thiếu, game sẽ dùng hình vẽ bằng code thay vào.

**Lưu ý:** **đừng để AI viết chữ hay số trong ảnh**, vì AI hay viết sai. Các chi tiết làm manh mối (số thuyền, ngày tháng, chữ viết tay) mình sẽ vẽ chồng lên ảnh bằng code, để chính xác tuyệt đối.

Mỗi prompt đã có sẵn câu "no text, no letters, no numbers, no watermark" ở cuối. Giữ nguyên câu đó.
